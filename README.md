# 次回司会ルーレット

会議の次回司会をルーレットで決めるための、1ファイル完結のWebツールです。
Notionのボタンで決めた結果を受け取り、「回って止まる」演出だけを担当します。

## 使い方

### Notion連携モード

URLにパラメータを付けて開くと、指定した人で必ず止まります。

```
index.html?winner=Bさん&history=Bさん,Aさん&members=Aさん,Bさん,Cさん,Dさん,Eさん
```

| パラメータ | 内容 |
|---|---|
| `winner` | 当選者。必ずこの人で止まります |
| `history` | 除外する履歴（カンマ区切り、左が最新）。盤面から消えます |
| `members` | メンバー一覧（カンマ区切り） |

`history` は先頭に `winner` を含んでいても構いません。盤面を作る前に取り除かれます。

このモードでは履歴の正をNotion側が持つため、ブラウザには何も保存しません。

### 単独モード

パラメータなしで開くと、ツール自身が抽選します。
過去に当たった人を除外し、全員が一巡すると自動でリセットします。
履歴はブラウザの localStorage に保存されます。

## 設定

ファイル冒頭の `<script>` ブロックだけで完結します。

```js
const MEMBERS = ["Aさん", "Bさん", ...];  // 単独モード用のメンバー
const EXCLUDE_PAST_WINNERS = true;         // 過去の当選者を除外するか
const EXCLUDE_COUNT = 0;                   // 0=全履歴 / 2=直近2人だけ除外
```

> このリポジトリは公開されています。`MEMBERS` に実名を書かないでください。
> 実際のメンバーはNotion側から `?members=` で渡してください。

## 構成

依存ライブラリなし。HTML / CSS / Canvas のみの単一ファイルです。
